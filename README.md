# bubbleTking's Playground

A personal app shelf for useful tools, playful experiments, and interactive
ideas. Projects are designed to be tried directly instead of presented as
static portfolio screenshots.

The live site supports English and Simplified Chinese and remembers the
visitor's language choice.

## Featured projects

- **Hearing Guardian**: a local-first macOS listening-break companion.
- **In Presence / 在场**: an AI-native interactive mystery experience.
- **Excel Diff Studio**: a private, browser-based spreadsheet comparison tool.
- **AI Status Watch**: a local Chrome extension for AI service status alerts.
- **Inheritance Tax Simulator**: an interactive business-succession model.

## Run locally

Requires Node.js 22 or newer.

```bash
npm install
npm run dev
```

Run the checks with:

```bash
npm test
```
